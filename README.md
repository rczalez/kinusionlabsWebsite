# Kinusion Labs - GitHub Pages
1. Creá un repo en GitHub, ej: `kinusionlabs.github.io` o `kinusion-labs`
2. Subí todo el contenido de este .zip (index.html + carpeta assets/) a la rama `main`
3. En GitHub: Settings > Pages > Source: Deploy from a branch > Branch: main / (root) > Save
4. Tu sitio quedará en https://<tu-usuario>.github.io/ o https://<tu-usuario>.github.io/kinusion-labs/
5. Para activar el formulario: creá un form en Formspree y reemplazá `https://formspree.io/f/your-id` en index.html
6. Para reemplazar la foto del fundador: subí tu foto a assets/founder.jpg y reemplazá el div .avatar por <img src="assets/founder.jpg">
